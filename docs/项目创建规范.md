# 项目创建规范

## 项目结构

每个具体片段项目位于 `projects/项目名/` 下。

```text
projects/
  2026-06-西游记-三打白骨精/
    PROJECT_BOARD.md
    details/
    outputs/
```

## PROJECT_BOARD.md

`PROJECT_BOARD.md` 是每个项目的唯一状态源，也是具体项目的轻量记忆层。

它保存：

- 顶层索引字段（项目状态、下一阶段、生命周期、关键全局索引）
- 上下文读取策略与 Token 预算
- 用户确认状态
- 时长与视频分段策略
- Hero Moment / 看点镜头
- Bridge Shot / 桥接分镜
- Blocking Map / 空间调度图
- Faction Layout / 阵营布局
- Prop State Machines / 道具状态机
- 各阶段结构化 YAML 补丁块
- 关键决策
- 资产引用
- 风险摘要
- 产物版本引用
- 待办事项

顶层 YAML 当前统一命名空间字段为：

```yaml

  updated_at:

```

说明：

- `project`：项目基础元数据（名称、Slug、创建和更新时间）。
- `state`：管线核心状态控制，包括当前主流程状态 `project_status`、下一步阶段 `next_stage`、生命周期 `lifecycle_flag`（`active / blocked / completed` 等）以及卡点说明 `blocker_note`。
- `routing`：当前路由阶段及允许的后续阶段，记录跳转原因。
- `runtime_policy`：运行期上下文读取及参考策略。限制 Agent 对 `docs/` 和 `.handoff/` 的默认读取。
- `project_config`：当前项目确认的制作档位、导演风格 ID、风格家族及 profile 路径、时长设置等。
- `confirmations`：阶段确认闸门。记录每一个阶段用户是否通过方案预览并进行显式确认。
- `active_versions`：记录每一个阶段当前落盘的最终版本号。
- `stage_index`：各阶段最终产物文件的索引映射（包含 primary/handoff 等文件路径），用于提供给下游读取。
- `cross_stage_summary`：跨阶段核心摘要信息（故事主线、核心角色、场景道具、风格与连续性关注点）。
- `read_policy`：定义项目级默认读取文件以及阶段定制读取策略。
- `stage_patches`：归档各阶段成功合并的补丁记录（patch_type、version、summary、files_created、files_updated）。


每个阶段分区统一使用结构化 YAML 补丁块，补丁壳如下：

```yaml
patch_type:
version:
status:
updated_at:
summary:
data:
```

显示规则统一为：

- 对话与黑板概览：中文优先，必要时带英文参数值
- `summary`：使用中文描述，建议在关键状态后附英文参数值
- 结构化字段：继续使用英文参数值，作为唯一机器可读口径

## 阶段确认闸门

以下阶段默认必须先给方案预览，用户确认后才允许落盘正式文件或推进阶段：

- `scene-script-adapter`：确认总时长、分段策略、剧本方案和 Story Beat 方向。
- `scene-design-builder`：确认角色方向、场景道具清单、统一视觉语言和参考强度。
- `scene-storyboard-director`：确认分镜结构、Hero Shot、Bridge Shot、Segment Plan 和 Blocking Map。
- `scene-video-prompt-builder`：确认分段提示词结构、参考图使用方案和连续性策略。

## details/

`details/` 是可选长内容区，不保存 Agent 思考过程，不保存废稿。

只保存正式但过长、不适合放在黑板里的内容：

- 完整剧本
- 完整分镜表
- 复杂参考对象分析
- 复杂风险说明
- 角色/场景/道具锁定卡
- 表演表
- 声音方案

## outputs/

`outputs/` 只保存可直接拿去使用的提示词、制作说明和发布素材文案。

当前 SceneForge 不负责生成图片、视频或音频。图片、视频和音频需要用户基于 prompt 在外部平台手动生成。

允许保存：

- 角色设定图 prompt
- 场景设定图 prompt
- 关键道具设定图 prompt
- 全场景资产总参考图 prompt
- 故事板图 prompt
- 视频分段提示词
- 一致性规则说明
- 声音制作说明 / 音乐 prompt / 拟音 prompt
- 发布文案
- 字幕文案
- 配音文案

不应默认保存或声称已生成：

- 最终图片
- 最终视频
- 最终音频
- 已嵌入文档的生成图

视频提示词当前不按模型分类，保持通用目录。

默认视频分段时长为 `10` 秒，对应顶层字段 `segment_duration_seconds`。若分镜阶段判断 10 秒承载不下关键表演，可在用户确认后改为 `15` 或混合分段。
