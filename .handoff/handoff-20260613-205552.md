## 可能根因排序

1. **loading/skeleton 占位未清理或被错误渲染到 feed**
   - 证据：横线和 `AI DIRECTOR IS WORKING` 同屏出现。
   - 需要检查 `active-agent-loading` 与相关 CSS。

2. **空内容 bubble 被过滤为 null，但父级/邻近样式仍保留大面积布局或边线**
   - 需要看实际 DOM，不要只看 React 条件渲染。

3. **thought bubble 没有出现在预期位置，或 status 没有正确更新**
   - 最新截图没看到 `思考中...` / `已处理 ...` 行，说明上轮 process row 设计可能没有接到真实数据。

4. **Markdown/分隔符仍来自 text 或历史内容，但 CSS 隐藏 `<hr>` 没覆盖真实节点**
   - 这个可能性下降，但仍需通过 DOM 验证。

5. **prompt card / confirm card 附近的 placeholder 与 loading 状态叠加**
   - 最新截图有确认按钮区域和工作中状态，可能是 prompt 生命周期与 run 生命周期交错。
