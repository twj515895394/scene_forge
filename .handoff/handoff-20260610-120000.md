## 1. 当前架构

### 1.1 Claude 桥接
- `claude --print --output-format stream-json --verbose` 流式输出
- `--session-id <uuid>` / `--resume <uuid>` 实现多连接会话隔离
- 首次消息注入两行上下文：
  ```
  读取 ./AGENTS.md（不是根目录的 CLAUDE.md）。当前项目: xxx，目录 projects/xxx/。
  ```
- Claude CWD = scene_forge 根目录，能访问 AGENTS.md、skills、所有项目
- 取消操作为 SIGINT 仅中断当前操作
- `+ 新会话` 按钮生成新 UUID

### 1.2 前端
- **UI 库**: shadcn/ui + Tailwind CSS + lucide-react
- **唯一主题**: Variant B（Swiss Neo-Geek Grid）
- **Lobby**: shadcn Card/Button/Input/Textarea/Badge/Alert/ScrollArea
- **ChatHistory**: 从 `~/.claude/projects/` 读取 JSONL 会话文件
- **activeStage**: 自动跟随 PROJECT_STATE.json，时间轴只读
- **阶段操作**: 旧 CLI 宏按钮已移除，改为对话驱动

### 1.3 后端 API

## 2. 当前已知问题

### 2.1 🔴 历史会话加载后 AI 回复不渲染
- **现象**: 点击历史会话，用户消息正常显示，但 AI 回复（thinking/tool_call/text）不显示
- **已排查**: API 返回 14 条消息正确，前端 `handleLoadSession` 生成 14 个 bubbles 正确，类型分布 `text,thought,text,tool_call,...`
- **已尝试**: 将 AI text 气泡从 `renderMarkdown()` 改为纯文本 + 红色边框，待验证结果
- **可能方向**: 渲染层 React 组件未正确挂载，或 CSS 导致不可见

### 2.2 🟡 聊天输入框超过 4 行后挤压变形
- 已改为 auto-resize textarea + ScrollArea 包裹 + `max-height: 200px`
- 待 CSS 编译错误修复后验证

### 2.3 🟡 实时流式输出偶尔不显示思考内容
- stream-json 的 thinking 事件和 text 事件分离推送，前端合并逻辑需验证

### 2.4 🟡 会话列表显示昨天的比今天的多
- 已修复：API 改为始终读取 workspace 根目录的 sessions
- 会话预览已剥离注入上下文，显示用户真实输入

## 6. 建议调试顺序

1. 先确认红色边框 AI bubble 是否出现（区分渲染问题 vs 数据问题）
2. 若出现：问题在 `renderMarkdown`，修 markdown 渲染器
3. 若不出：问题在 React 组件挂载或状态更新，查 VariantB 渲染循环
4. 然后验证实时流式对话是否正常
5. 最后跑一次完整阶段流转测试
