## 2. 下一步工作规划 (Next Session Focus)

### ① 新项目全流程测试 (E2E Testing of a New Project)
*   **测试目标**：在不手动改动数据库或绕过校验的情况下，建立一个全新项目，并测试全流程状态机流转。
*   **测试重点**：
    1.  从 `scene-topic-gate` 开始，每一步均需正常使用 `node cli.js start --stage <stage>` 开启阶段，通过对话设计或参考对应的 `SKILL.md`，并在用户确认方案后，正式写入 `outputs/` 或 `details/`。
    2.  运行 `node cli.js complete --stage <stage>` 触发校验、生成 Handoff 并使状态机顺利向前流转，直至 `publish_review` 归档。
    3.  验证侧边栏文件展示与右侧预览面板渲染无报错。

### ② 各阶段 Skill 与 Output Contract 架构设计优化 (Skill Refactoring Focus)
*   **现状痛点**：目前各阶段的 `SKILL.md` 与 `output-contract.md` 划分偏粗，使得某些阶段（例如 `storyboard` 和 `audio`）承载的任务过于臃肿，导致提示词膨胀和输出内容冗长（包含控制、风格、混音等多重复杂维度）。
*   **优化思路**：
    *   **职责更细、更专业化**：将重点 Skill 拆分为更加专注细分的子 Skill。例如：
        *   将 **Storyboard Director** 拆分为 **Storyboard Layout Planning**（镜头布局与景别）和 **Storyboard Prompt Compiler**（画质、渲染风格 prompt 生成器）。
        *   将 **Audio Director** 拆分为 **Audio Sequence & Timing**（声画同步与静默轴）和 **Foley & Music Prompters**（音效/拟音 prompt 独立生成）。
    *   **子契约隔离**：使 `output-contract.md` 对齐这些子模块，减少由于单一文件格式校验失败而阻塞整个阶段状态流转的风险，并有利于在不同题材中只组装所需的特定子契约。
