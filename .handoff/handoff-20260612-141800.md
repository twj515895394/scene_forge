## 3. 上期遗留且需继续集成的测试指南

在完成上述 Bug 修复（运行 `pnpm run build` 并成功启动服务）后，请继续验证以下核心 SOP 管线测试：
1. **宏操状态流转**：通过点击侧边栏的 Pipeline 卡片或发送文本命令，测试能否驱动后端拉起 Claude 自动执行 CLI 任务。
2. **静默授权卡片行为**：
   - 验证在执行写盘/执行工具时，前端弹出“系统授权申请”卡片。
   - **严格校验**：授权卡片弹出时，输入框必须被禁用（提示“等待授权决策...”），且授权通过后没有任何多余的用户文字回复气泡。
3. **开启/关闭自动授权测试**：验证顶栏“自动授权 (Auto-Approve)”开启后，是否带上 `--dangerously-skip-permissions` 静默写盘而不再产生卡片拦截。
