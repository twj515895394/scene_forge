## 本轮核心改动

### 1. output-contract 降级为短机器契约

三个 `output-contract.md` 已从长规则书压缩为短契约：

```text
.agents/skills/scene-design-builder/references/output-contract.md
.agents/skills/scene-storyboard-director/references/output-contract.md
.agents/skills/scene-video-prompt-builder/references/output-contract.md
```

当前行数：

```text
design: 99 lines
storyboard: 119 lines
video_prompts: 119 lines
```

短契约只保留：

- validator 需要的字段 marker
- 必交文件路径
- board / manifest 索引要求
- 上下游继承边界
- 禁止完成形态

### 2. 规则迁移图

已新增规则迁移图：

```text
.agents/skills/scene-design-builder/references/output-contract-migration-map.md
```

用途：

- 记录旧 `output-contract.md` 中每类规则迁移到哪个文档
- 防止后续误以为规则被删除
- 给后续 skill 重构提供标准参考样式

注意：storyboard 与 video_prompts 的短契约通过相对路径引用该迁移图。

### 3. SKILL.md 默认读取顺序调整

已修改：

```text
.agents/skills/scene-design-builder/SKILL.md
.agents/skills/scene-storyboard-director/SKILL.md
.agents/skills/scene-video-prompt-builder/SKILL.md
```

调整后：

- 默认读取 `workflow.md`
- 默认读取 `required-deliverables.md`
- 默认读取 `review-checklist.md`
- 默认读取对应 prompt template
- `output-contract.md` 只在修复字段、实现 validator、排查 board/manifest 漂移时按需读取

### 4. 中文主导参考文档

已中文化三个 skill 的核心 reference 标题和主要章节：
