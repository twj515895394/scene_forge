### 3. Storyboard 控制板 / 风格板职责

已明确：

- 控制故事板是视频生成默认主参考板，负责动作、镜头调度、空间关系和连续性。
- 风格故事板是辅助参考板，负责角色渲染、场景质感、灯光影调、情绪氛围和最终画面质量。

控制板已要求：

- 镜头语言专业
- 分镜工整
- 画面不重叠
- 红色箭头表示人物运动方向
- 蓝色摄影机箭头 / 蓝色镜头图标表示摄影机运动方向
- 红蓝箭头必须在每个分镜画面区内部出现，不能只放在底部轨道栏

相关文件：

- `.agents/skills/scene-storyboard-director/references/storyboard-prompt-template.md`
- `.agents/skills/scene-storyboard-director/references/review-checklist.md`

## 下一步建议

下一次会话建议做“产物瘦身 / 阶段交付简化”专项。

建议先做 inventory，不直接删规则：

1. 统计当前 SOP 每个阶段的必交文件、推荐文件、可选文件。
2. 区分三类产物：
   - 下游必须读取
   - validator / board / manifest 必须存在
   - 只用于解释或中间推理，可合并或降级
3. 对每个阶段给出瘦身方案：
   - 必留
   - 合并
   - 改为按需生成
   - 删除或降级为 review 摘要
4. 再生成 issues 并逐步修改 skill / validator / web console 展示。

优先关注：

- `storyboard` 阶段 details 文件是否过多
- `video_prompts` 阶段中文/英文/整片/segment 拆分是否需要默认全产出
- `audio`、`performance` 是否存在可合并的 detail / pack
- `design` 的 prompt、角色说明书、空间种子、道具状态机哪些必须独立落盘
