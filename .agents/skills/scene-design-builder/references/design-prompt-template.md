# 设计 Prompt 模板

`outputs/design_prompts/角色说明书图片提示词_v*.md` 必须是中文主导的角色说明书板 prompt。

## 必须使用的体裁

```markdown
# 角色说明书图片提示词

## 复制专用主 Prompt

生成一张角色说明书板 / character bible sheet / character design board。

## 角色基础信息区

## 多视角区

正面、3/4、侧面、背面。

## 轮廓剪影区

## 表情系统区

6 到 9 个剧情表情。

## 微表情区

2 到 4 个微表情。

## 动作姿态区

4 到 6 个剧情动作姿态。

## 关键道具交互区

## 服装 / 配件 / 材质细节区

## 比例对照区

## 物理与安全边界区
```

## 语言要求

- 默认中文主导。
- 英文只作为锚词、风格词和板式名词辅助。

## 禁止形态

不要把角色说明书图片 prompt 写成：

```text
single portrait
poster
cinematic portrait
hero poster
character poster
```

这类输出不能替代角色说明书板。
