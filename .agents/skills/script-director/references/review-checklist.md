# Script Director Review Checklist

在输出 `03_SCRIPT_DIRECTION.md` 前逐项检查。

## Story Canon

- [ ] 所有关键 Story Beats 被覆盖。
- [ ] 没有重新发散已确认故事方向。
- [ ] 结局、人物关系和 immutable story facts 没有改变。
- [ ] rewrite / preserve / original 模式继承正确。

## Visual Canon

- [ ] 角色身份、服装、发型和关键外观锁没有被无意改变。
- [ ] 场景空间关系符合 Stage 02。
- [ ] 道具没有凭空出现、消失或改变状态。
- [ ] 如发生换装、破损、移动或状态变化，剧本中有明确发生点。

## Scene Structure

- [ ] 每个 `SCN_###` 都关联至少一个 `BEAT_###`。
- [ ] 每场都有明确目标、冲突变化和结束状态。
- [ ] 场次之间因果成立。
- [ ] 没有功能完全重复的连续场次。

## Dialogue

- [ ] 对白符合角色身份和关系。
- [ ] 对白能被真实表演，不是纯说明文字。
- [ ] 没有用对白重复画面已经表达的信息。
- [ ] 必须保留的台词被准确继承。

## Performance

- [ ] 关键情绪不是只写“开心/生气/悲伤”。
- [ ] 重要对白附近有可观察表演动作。
- [ ] 主要角色都有 gaze、body center、gesture 和 signature gesture。
- [ ] Reaction timing 和 pause/hold 使用在真正需要的位置。
- [ ] 喜剧/反差节奏包含 setup / pause / payoff 意识。
- [ ] 风格化动作如存在，包含 anticipation / impact / hold / recovery。
- [ ] 没有为了夸张效果让角色性格崩坏。

## Continuity

- [ ] 关键 Action Continuity Chains 已建立。
- [ ] 关键 Emotion Continuity Chains 已建立。
- [ ] Prop State Timeline 与正文一致。
- [ ] Blocking 不违反场景空间锁。
- [ ] 场次结束状态能自然成为下一场输入状态。

## Duration

- [ ] 每场有合理估时。
- [ ] 估时总和与目标总时长基本一致。
- [ ] 没有靠不现实语速压缩时长。
- [ ] 必要的停顿、反应和高潮时长没有被错误删除。

## Storyboard Readiness

- [ ] Hero / Reaction / Bridge 候选已标记。
- [ ] 必须看清的表情和道具动作已标记。
- [ ] 需要建立空间关系的位置已标记。
- [ ] 没有越界写正式 Shot List。

## 输出纪律

- [ ] 唯一正式输出是 `03_SCRIPT_DIRECTION.md`。
- [ ] 没有单独输出 performance sheet 或 beat table。
- [ ] 没有写最终视频生成 Prompt。
- [ ] 没有声称已生成媒体资产。
- [ ] Downstream Handoff 完整。
